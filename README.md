# Modelisation-et-prediction-du-prix-des-caburants-2023-et-2024-en-France
L'objectif est de charger et traiter les données sur le prix des carburants avec Spark en respectant les étapes suivantes:  Collecter des données, Préparer les données, Visualiser les variations des prix des carburants, Modéliser l’évolution des prix et prédiction du prix du lendemain.
